Tool reference

Twelve registered Hermes tools share one guarded execution boundary. Select a tool to see its purpose and context.

violin_exec

Execute one guarded command against approved scope

Context: All Phases

violin_submit_finding

Submit validated vulnerability bound to signed execution receipts

Context: Validation / Reporting

violin_record_ptt

Create, start, refresh, close, or cancel an engagement task

Context: Workflow State

violin_record_hypothesis

Create or update scoped hypothesis with cheapest test and kill criteria

Context: Planning

violin_review_batch

Review completed command burst and settle engagement state

Context: Synchronization

violin_exec_burst

Execute bounded batch of commands with batch review requirements

Context: Execution

violin_rebind_pending_batch

Rebind pending batch after operator confirmation

Context: Review Flow

violin_target

Resolve approved target and scope authorization parameters

Context: Discovery

violin_status

Inspect active tasks, routed skills, and current blockers

Context: Diagnostics

violin_heartbeat_done

Clear completed operator review heartbeat

Context: Safety

violin_exec_status

Query background process execution and stream logs

Context: Monitoring

violin_exec_cancel

Cancel tracked background execution process

Context: Safety

For parameter schemas, see the typed registry on GitHub ↗.
